# 🔧 Настройка переменных окружения

Руководство по настройке переменных окружения для приложения Seller (Server, Client, Client Admin).

## 📁 Структура файлов

- **Root `.env`** - Глобальные переменные для Docker Compose
- **`server/.env`** - Переменные сервера
- **`client/.env`** - Переменные клиента
- **`client_admin/.env`** - Переменные админ-панели

## 🚀 Server (NestJS) - `server/.env`

```env
NODE_ENV=production
PORT=3002

# База данных
DATABASE_URL=postgresql://seller_prod:YOUR_STRONG_DB_PASSWORD@postgres:5432/seller_prod?schema=public
DB_NAME=seller_prod
DB_USER=seller_prod
DB_PASSWORD=YOUR_STRONG_DB_PASSWORD
DB_PORT=5432
PRISMA_CLIENT_ENGINE_TYPE=library

# JWT
JWT_SECRET=YOUR_SUPER_SECRET_JWT_KEY_AT_LEAST_32_CHARACTERS_LONG
JWT_EXPIRES_IN=24h

# MinIO
MINIO_ENDPOINT=minio
MINIO_PORT=9000
MINIO_USE_SSL=false
MINIO_ACCESS_KEY=YOUR_MINIO_ACCESS_KEY
MINIO_SECRET_KEY=YOUR_MINIO_SECRET_KEY_MIN_8_CHARS
MINIO_BUCKET_PUBLIC=public
MINIO_BUCKET_PRIVATE=private
MINIO_BUCKET_MEDIA=media
MINIO_CONSOLE_PORT=9001

# CORS
CORS_ORIGIN=http://localhost:3000,http://localhost:3001,http://yourdomain.com:3000,http://yourdomain.com:3001
```

## 🌐 Client (Next.js) - `client/.env`

```env
# API URL
API_URL=http://backend:3002/api
NEXT_PUBLIC_API_URL=http://yourdomain.com:3002/api

NODE_ENV=production
NEXT_TELEMETRY_DISABLED=1
```

## ⚙️ Client Admin (React) - `client_admin/.env`

```env
VITE_API_URL=http://backend:3002/api
```

## 🌍 Root `.env` (Docker Compose)

```env
# База данных
DB_NAME=seller_prod
DB_USER=seller_prod
DB_PASSWORD=YOUR_STRONG_DB_PASSWORD
DB_PORT=5432

# MinIO
MINIO_ENDPOINT=minio
MINIO_PORT=9000
MINIO_USE_SSL=false
MINIO_PUBLIC_URL=http://yourdomain.com:9000
MINIO_ACCESS_KEY=YOUR_MINIO_ACCESS_KEY
MINIO_SECRET_KEY=YOUR_MINIO_SECRET_KEY_MIN_8_CHARS
MINIO_BUCKET_PUBLIC=public
MINIO_BUCKET_PRIVATE=private
MINIO_BUCKET_MEDIA=media
MINIO_CONSOLE_PORT=9001

# Backend
PORT=3002
NODE_ENV=production
JWT_SECRET=YOUR_SUPER_SECRET_JWT_KEY_AT_LEAST_32_CHARACTERS_LONG
JWT_EXPIRES_IN=24h

# CORS
CORS_ORIGIN=http://yourdomain.com:3000,http://yourdomain.com:3001,http://localhost:3000,http://localhost:3001

# API URL
CLIENT_API_URL=http://yourdomain.com:3002/api
ADMIN_API_URL=http://yourdomain.com:3002/api
```

## 🔐 Безопасность

### Пароли и секреты

- **JWT_SECRET**: Минимум 32 символа
- **MINIO_SECRET_KEY**: Минимум 8 символов
- **DB_PASSWORD**: Сложный пароль (12+ символов)

### URL для сред

- **Разработка**: `localhost` или имена контейнеров
- **Продакшн**: Реальные домены/IP

### HTTPS

Для HTTPS измените:

```env
MINIO_USE_SSL=true
MINIO_PUBLIC_URL=https://yourdomain.com:9000
CLIENT_API_URL=https://yourdomain.com:3002/api
ADMIN_API_URL=https://yourdomain.com:3002/api
CORS_ORIGIN=https://yourdomain.com:3000,https://yourdomain.com:3001
NEXT_PUBLIC_API_URL=https://yourdomain.com:3002/api
VITE_API_URL=https://yourdomain.com:3002/api
```

## 🔄 Быстрая настройка

```bash
# Копирование шаблонов
cp .env.production.example .env
cp server/.env.example server/.env
cp client/.env.example client/.env
cp client_admin/.env.example client_admin/.env

# Настройка значений
```

## ⚠️ Важные замечания

1. **Не коммитьте `.env` файлы** - они содержат чувствительную информацию
2. **Разные секреты** для разработки и продакшна
3. **Тестируйте конфигурацию** перед развертыванием
4. **Обновляйте CORS_ORIGIN** для всех доменов
5. **Совпадение учетных данных БД** между root `.env` и `server/.env`

## 🐳 Docker

В Docker Compose:

- Используйте имена контейнеров для внутренней коммуникации
- Внешние URL для клиентского доступа
- Все сервисы в сети `seller_network`
